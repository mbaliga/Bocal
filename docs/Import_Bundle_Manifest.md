# Bocal — Complete ChatGPT Bundle

Prepared: 12 August 2026

This bundle consolidates the Bocal project artifacts recovered from ChatGPT into one package.

## Included

- Latest Bocal product/engineering handoff and supporting product handoff documents.
- Latest saxophone validation / TonalEnergy parity specification.
- Alto saxophone 3D model specialist brief.
- Music-learning baseline/build brief.
- Current Bocal prototype screenshots recovered from the ChatGPT Library.
- All eight recovered ChatGPT-generated Bocal source/package snapshots in original ZIP form.
- Extracted copies of each recovered package so the source can be browsed without opening nested ZIPs.

The recovered package snapshots include validated web source, standalone/static hosting builds, Android source, research material, 3D woodwind model tooling/assets, and the complete handoff package.

## Deliberately excluded

Personal saxophone reference photographs and the two user-supplied motion-reference videos are not included here. They were source/reference inputs rather than publishable Bocal product artifacts and were previously kept out of the public-repository import set.

## Integrity

`SHA256SUMS.txt` contains checksums for every file in this bundle except the checksum file itself.
