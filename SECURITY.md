# Security policy

Bocal is a local-first application. It has no account service or telemetry
backend, and microphone recordings and practice data are intended to remain on
the user's device.

## Reporting a vulnerability

Please report security issues privately to [bocal@asystemofcells.com](mailto:bocal@asystemofcells.com).
Include the affected version or commit, device and browser/Android version,
reproduction steps, and the smallest safe proof of impact. Do not attach private
recordings, credentials, or other personal data.

Until the first signed production release is published, the supported test target
is the current `main` branch. Debug APKs are for development and QA only and must
not be distributed as production builds.

We will acknowledge a report as soon as practical, investigate it, and coordinate
disclosure with the reporter when a fix is available.
